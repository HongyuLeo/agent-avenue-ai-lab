# Agent Avenue AI — Public 2.2.0

## What changed

- Added complete Simplified Chinese, English, and Spanish interface localization.
- Simplified Chinese remains the default language.
- Added an always-visible `中文 / English / Español` selector in the application header.
- The selected language is saved in `%LOCALAPPDATA%\AgentAvenueAI\language.txt` and restored on the next launch.
- Localized card names, training controls, evaluation results, game prompts, outcome explanations, help text, error dialogs, window titles, and exported game logs.
- Added automated rendering checks for all three languages.
- Kept the game rules, checkpoint format, and pretrained model unchanged.

## Windows download

Download `AgentAvenueAI-Public-v2.2.0-Windows.zip`, extract the whole archive, and run `AgentAvenueAI.exe`.

The release archive includes the illustrated card assets and the same pretrained checkpoint with 17,366,354 self-play games.
