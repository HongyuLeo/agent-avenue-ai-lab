# Original card artwork

These eight human-agent illustrations were created specifically for Agent Avenue AI Lab under the visual direction of Liu Hongyu with assistance from an AI image-generation tool.

They are original project assets and do not copy or contain artwork from the commercial game. Character names and mechanics are rendered separately by the application so the art remains language-neutral.
